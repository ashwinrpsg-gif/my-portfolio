ML + NLP

PlayGuard AI — Play Store Safety & Trust Inspector

A Python application that analyses Google Play app details and user reviews to highlight potential trust and safety concerns.

  • Collects application information and relevant user reviews.
  • Uses TF-IDF text features and a Multinomial Naive Bayes model to classify potentially spam-like reviews.
  • Uses pretrained DistilBERT sentiment analysis to estimate review sentiment.
  • Combines sentiment, keyword checks, and project-defined rules to calculate a risk indication.
  • Displays results through a Streamlit interface and Plotly visualisations.
Python Streamlit scikit-learn TF-IDF Naive Bayes DistilBERT Plotly

The risk indication is generated by this project. It is not an official Google Play rating, and model predictions are not proof that a review is fake.
